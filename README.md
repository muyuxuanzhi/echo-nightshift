# ECHO

> 一台电脑，两个时间，一个共享的账号。
> 你在「现在」读到的每一份记录，都是「七天前」的另一个你写下的；
> 你在「现在」写下的每一封信，又会被「七天前」的自己读到。

一款复古终端风格的双线悬疑解谜 Demo。没有场景、没有立绘，整个游戏就是一台老旧值班终端——玩家通过「收发邮件」在两条时间线之间传递线索，边查案边吐槽，拼出七天前那个消失的夜班同事到底经历了什么。

## 在线试玩

克隆仓库后直接用浏览器打开 `index.html` 即可试玩（纯前端单文件，无需安装任何依赖）。

如果仓库已开启 GitHub Pages，也可以直接访问对应的 Pages 链接在线试玩。

## 玩法简介

- **双线穿越**：「现在」与「七天前」共用同一台终端账号，靠写信/读信（即存档/读档）互相传递线索。
- **终端解谜**：`ls` 查看文件、`cat 文件名` 阅读、`decrypt 文件名 密码` 解密加密文件，密码需要在另一条时间线里找到。
- **吐槽独白**：主角是个满身班味的打工人，查案途中不忘疯狂吐槽，冲淡恐怖氛围。
- **多重结局线索**：解密事故报告、私人日记、查看值班室照片等,拼凑出完整真相后触发结局。
