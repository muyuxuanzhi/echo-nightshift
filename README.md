# 镜中来客 · 苔丝与反钟镇

> 一面会认字的镜子，两个世界。
> 镜子这头是「反钟镇」——钟永远卡在下午六点，记忆倒着长；
> 镜子那头是「阁楼」——一个爱琢磨、爱恶作剧的女孩。
> 他们只能靠「写信」互通，用同一套「数字根」规则，把时间重新续上。

一款复古终端风格的解谜 Demo。没有场景、没有立绘，整个游戏就是一台带 CRT 扫描线的老旧终端。玩家切换镜子两端，把散落在物件文字里的**钟码（0–9 的数字碎片）**收集起来，用统一的**数字根**规则开四扇门、走完三封信，解开反钟镇卡在下午六点的困局。

## 在线试玩

纯前端单文件，克隆后直接用浏览器打开 `index.html` 即可试玩，无需安装任何依赖。若仓库已开启 GitHub Pages，也可直接访问 Pages 链接在线试玩。

## 玩法简介

- **双端写信**：镜子两端各是一个世界，靠「写信 / 看信」互通线索（对应故事里「对着镜子写字，等雾气显字回信」）。
- **统一数字根解谜**：全游戏只有一条规则——把选中的钟码加总，超过一位就逐位再相加，直到只剩一位。每扇门刻着「根数」和「契数」，凑对即开，解法不唯一。
- **钟码收集**：物件文字里藏着 0–9 的数字碎片，读物件时自动收进口袋，用 `codes` 查看。
- **终端命令**：`ls` 查看、`cat 名称` 细看、`root` 试算数字根、`open 门名 钟码...` 开门，顶部「钟码算盘」可可视化归约。
- **吐槽独白**：主角一路碎碎念，冲淡谜题的沉闷，保持爱丽丝式的轻盈荒诞。

## 项目结构

```
index.html          游戏本体（HTML + CSS + 原生 JS，单文件，无外部依赖）
解谜流程.md         完整解谜流程 / 攻略（数字根规则、钟码分布、四扇门、通关步骤）
DESIGN.md           一页纸玩法设计方案（数字根版）
故事_镜中来客.md    叙事脚本（苔丝与反钟镇 · 爱丽丝式荒诞）
故事_暮镜与回声.md  另一版叙事脚本（灰儿 / 回声镇 · 七天循环，暂未实现）
```

## 开发说明

纯原生 HTML/CSS/JavaScript 实现，状态通过 `localStorage` 持久化，方便调试与重开。当前剧情走「镜中来客」线（苔丝 × 格雷），数字根为唯一解谜规则。
